# 에폭시 물성 → 콘크리트 응력 · 에폭시 힘 · 파단 판정 (Case 1)

**정보가 없으면 추정하지 말고 묻는다.** 특히 판정 한계 (콘크리트 인장강도 f_ct) 와 변형률 단위 (%) 는 짐작으로 채우지 않는다. 배경 · 용어 · 판정 기준 · 식은 `references/research.md` 에 있다.

## 순서

1. **입력 확인** – 케이스마다 아래 값을 받는다. 빠진 값은 기본값을 쓰고, 기본값이 없는 값은 묻는다.
   - 에폭시: 항복강도 `sy` · 인장강도 `fu` (MPa), 초기 탄성계수 `E1` (MPa, 기본 100), 파단 변형률 `eu` (%) – 또는 다점 곡선 `curve` = `ε%:σ;ε%:σ;…` (원점 제외)
   - 콘크리트: `Ec` (MPa, 기본 30,000) 또는 `fck` (MPa → E_c, f_ct 자동), 인장강도 한계 `ft` (MPa, 여러 개는 `3;4;5`) – **기본값 없음**
   - 모델: 균열폭 `w` (기본 0.2 mm), `Lc` (6,000 mm), `dT` (20 ℃ 하강), `alpha` (1e-5)
2. **케이스 CSV** – 세션 임시 폴더에 UTF-8 로 쓴다.
   ```
   name,sy,fu,E1,eu,curve,Ec,fck,ft,w
   2-5_E100_150,2,5,100,150,,30000,,3;4;5,
   ```
3. **계산** – 기본은 식. ANSYS 는 사용자가 분명히 요청할 때만 (라이선스 1석, bilinear · L_c 6,000 mm · ΔT −20 ℃ 고정).
   - 식: `powershell -ExecutionPolicy Bypass -File scripts\solve_case1.ps1 -CasesCsv <in.csv> -OutCsv <out.csv>`
   - ANSYS: `... scripts\run_ansys_case1.ps1 -CasesCsv <in.csv> -OutCsv <out.csv> -WorkDir <새 폴더>` (`-DryRun` 은 입력 파일만 생성)
4. **엑셀** – `... scripts\build_excel.ps1 -ResultsCsv <out.csv>[,<out2.csv>] -OutXlsx <사용자 폴더>\case1_판정_<요약>.xlsx`. 같은 이름이 있으면 `_2` 를 붙여 새로 만든다 (덮어쓰지 않음).
5. **보고** – 엑셀 경로와 아래 표를 채팅에 준다. 판정이 갈린 이유를 한두 줄 붙인다.

## 출력 형식

엑셀 `결과` 시트 (케이스 = 열): 입력 물성 → 콘크리트 응력 σ_c1~5 (MPa) → 에폭시 힘 1~4 (N, 스프링당) · 에폭시 응력 → 최대 변형률 (%) → 평형 위치 → 에폭시 파단 → 인장강도별 판정 (O / 균열 / 파단 / 한계) → 필요 최소 변형률 (%). `해석조건` 시트: 모델 · 식 · 판정 기준 · 색 범례.

채팅 표:

| 케이스 | 콘크리트 응력 (MPa) | 에폭시 힘 (N/스프링) | 최대 변형률 (%) | 에폭시 | 판정 (f_ct = …) |
|---|---|---|---|---|---|
| 2-5_E100_150 | 4.6664 | 233.32 | 133.5 | - | 3.0 균열 · 5.0 O |

- 판정: 균열 = σ_c > f_ct, 파단 = 평형 변형률 > 파단 변형률, 한계 = σ_c 가 f_ct ± 0.005 MPa 이내 (실제 응력과 필요 최소 변형률을 같이 말한다).
- 파단 케이스의 수치는 끝점 너머로 곡선을 연장한 가상값임을 밝힌다.
- 숫자와 단위는 한 칸 띄운다 (340 %, 2.65 MPa).
